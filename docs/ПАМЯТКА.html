01Что такое NautiBay

03Как сайт обновляется

Есть две копии одного сайта:

  • Рабочая — на твоём компьютере, открывается по адресу localhost. Видишь только ты. Тут проверяют правки.
  • Боевая — nautibay.vercel.app. Видят все.

Правка доходит до боевого сайта по цепочке:

правка в коде → снимок версии (commit) → загрузка в хранилище (push) → Vercel сам собирает и публикует (deploy) → через ~1 минуту сайт обновлён

Пока не сделан push — на боевом сайте ничего не меняется. Именно поэтому финальный дизайн, который делали раньше, не попал на сайт: правки сохранили в файлах, но снимок и загрузку не сделали.

05Что нужно, чтобы запустить полностью

Главное · нужно твоё действие

Подключить новую базу данных Supabase

Создать аккаунт и проект может только владелец — я не могу. Дальше всё остальное делаю я.

  1. Открыть supabase.com, войти или зарегистрироваться (бесплатно, по email или через GitHub).
  2. Проверить список проектов. Если есть старый xmgdzmbzrlhxjnpkhxdp — нажать Restore (вернутся и старые данные). Если нет — New project, любое имя, регион ближе к тебе, придумать пароль базы.
  3. Зайти в Project Settings → API, скопировать Project URL и anon / publishable key.
  4. Прислать эти два значения мне в переписку.
  5. Я пропишу их в .env.local, запущу 3 готовых скрипта (создадут таблицы и хранилище фото), проверю и опубликую.

После этого каталог, продажа лодки и аккаунты заработают. Останется подключить домен nautibay.com — это делается в панели Vercel, могу подсказать пошагово.

07Как передавать доработки

Чтобы продолжить работу со мной — в любой новой сессии:

  • Открыть проект C:\Users\Lenovo\yacht-marketplace в Claude Code (или попросить меня переключиться в эту папку).
  • Описать правку обычными словами: «сделай кнопку крупнее», «поменяй текст на главной», «добавь раздел про страхование». Технические названия знать не нужно.
  • Картинка-образец: сохранить её в галерею или «Загрузки» и назвать мне имя файла — я заберу сам. Вставленную прямо в чат картинку я в файл вытащить не могу.
  • Я показываю результат на localhost до публикации. На боевой сайт ничего не уходит, пока не скажешь «загружай».

Если работу будет продолжать другой человек или другой инструмент — этой памятки и раздела 02 достаточно, чтобы понять устройство проекта.

08Слова, которые будут встречаться

localhost
Сайт на твоём компьютере, только для проверки правок. Не виден в интернете.
боевой сайт
Публичная версия — nautibay.vercel.app.
GitHub
Онлайн-хранилище кода. «Сейф», куда складываются готовые версии.
Vercel
Хостинг. Показывает боевой сайт и сам его пересобирает, когда код попадает на GitHub.
Supabase
База данных: объявления, фото, аккаунты. Отдельный внешний сервис.
commit (коммит)
Снимок версии кода — фиксируется на компьютере.
push (пуш)
Загрузка снимка на GitHub. Запускает обновление боевого сайта.
deploy (деплой)
Сборка и публикация боевого сайта. Vercel делает сам.
migration (миграция)
Готовый скрипт, который создаёт таблицы в новой базе данных.
.env.local
Файл с адресом и ключом базы. Без него каталог не работает.
