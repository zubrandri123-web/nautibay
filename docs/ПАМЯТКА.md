## 01 · Что такое NautiBay

**NautiBay.com — Yacht Marketplace.** Международный маркетплейс яхтенного сообщества:
продажа лодок; позже — аренда, морская рыбалка с капитаном, поиск капитана и экипажа,
каталог услуг и магазинов. Сайт на 9 языках.

Аудитория — в основном Средиземноморье (Франция, Испания, Италия, Греция, Хорватия,
Турция, Португалия, Мальта, Черногория) + Германия, Великобритания, США.

## 03 · Как сайт обновляется

Две копии одного сайта:

- **Рабочая** — на компьютере, адрес `localhost`. Видишь только ты, тут проверяют правки.
- **Боевая** — `nautibay.vercel.app`. Видят все.

Цепочка публикации:

```
правка в коде → снимок версии (commit) → загрузка на GitHub (push)
   → Vercel сам собирает и публикует (deploy) → через ~1–2 минуты сайт обновлён
```

Пока не сделан **push** — на боевом сайте ничего не меняется.

Три команды для загрузки (по очереди, в терминале в папке проекта):

```
git add -A
git commit -m "короткое описание правок"
git push
```

## 05 · Что сделано в разработке (всё на боевом сайте)

**Внешний вид / бренд:**
- Бренд **NautiBay.com — Yacht Marketplace** везде (меню, вкладка, © в подвале)
- Тёмно-синяя тема, 3D-кнопки: синяя = перейти, зелёная = подтвердить, красная = отмена
- Цвета кнопок: **небесно-голубой** и **алый**
- Фон главной — фото марины; узкая высокая карточка; роза ветров (чёрно-белый медальон, N/E/S/W)
- Плитки СКОРО: «Причалы и хранение», «Арендовать лодку», «Морская рыбалка с капитаном»,
  «Найти капитана/экипаж», «Услуги и магазины»
- Вход всегда на **английском**; язык браузера из наших 9 подхватывается, остальные → английский
- Шапка на телефоне — по центру, не налезает

**Вход / аккаунт:**
- Пароль: показать/скрыть (глазик) + индикатор надёжности + «минимум 8 символов»

**Объявление о лодке — рабочий поток целиком:**
- Форма: тип, цена + **валюта (EUR/USD/GBP/CHF)**, год (можно приблизительный), длина/ширина/
  осадка **в метрах или футах** (переключатель, хранится в метрах), полный список стран мира
  (названия на языке пользователя), необязательные поля не блокируют отправку, ошибки видны
- **Контакты продавца**: телефон (+ WhatsApp/Telegram), email, заметка. Видны только вошедшим;
  гость видит «Войдите, чтобы связаться»
- Согласие **opt-in** на продвижение объявления в соцсетях
- **Просмотрщик фото**: тап → полный экран, свайп/стрелки, счётчик, закрытие
- **«Мои объявления»**: правка, «Продано», «Снять с продажи», «Вернуть», удалить
- Каталог: фильтры (тип, цена, год, длина в метрах, состояние, материал, топливо, страна,
  бренд, «рядом со мной»); в карточках и на странице лодки — «12 м (39 фт)», название страны

## 07 · Решения, которые уже приняли

### Модель доступа

| Кто | Что может |
|---|---|
| **Гость (не вошёл)** | Смотрит каталог, фото, характеристики, цену — сколько угодно. Не видит контакты продавца, не может писать. При попытке связаться — «Войдите». |
| **Покупатель (вошёл, бесплатно)** | Видит контакты продавца, может написать. Регистрация бесплатна всегда. |
| **Продавец / услуга (вошёл + позже оплатил)** | Размещает объявление / анкету. Оплата закрывает **публикацию**, не просмотр. |

Само объявление (фото, характеристики, цена) — **публичное**, чтобы его находил Google.
За входом только **контакт и переписка** (защита от спама владельцам лодок).

### Продвижение в соцсети — только с согласия

Галочка **opt-in**, по умолчанию НЕ отмечена. Поставил → продвигаем на других площадках.
Не поставил → нет. Без галочки — никогда. Локация в промо — только **регион/район**.

### Единицы измерения

Основная — **метры** (Средиземноморье меряет в метрах). В объявлении рядом показываем футы.

### Комьюнити

Встроенный форум/чат не делаем (пустой отпугивает, нужна постоянная модерация).
Позже — ссылка на Telegram.

### Раздел «Найти капитана / экипаж»

Капитаны и экипаж сами подают анкету (выходят в море, свои условия). Пользователи и
капитаны договариваются напрямую — площадка сводит. Для капитанов размещение анкеты
платное, символически.
